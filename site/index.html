Verify an address

A separate SeedSigner tool from signing. You give the device a wallet descriptor, then point its Verify Address tool at an address, and it derives through the wallet's addresses to prove that one belongs to it. No transaction involved — and note that during signing the device verifies change on board, so you never scan an address at it there.

Sign a message

Signs arbitrary text with the key at one derivation path, rather than spending anything. The QR carries the path and the message together, so the device knows which key to use.

What exactly is being signed?
